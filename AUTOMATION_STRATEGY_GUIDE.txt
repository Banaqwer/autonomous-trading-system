TROUBLESHOOTING:

Problem: Task Scheduler shows "Task not found"
   Solution: Verify file path is correct in task
             Right-click task → Properties → Actions tab

Problem: Bot doesn't run at 9:30 AM
   Solution: Verify:
             - Computer was on at 9:30 AM
             - Task is enabled
             - Time is set to 09:30 AM
             - Trigger is set to "Daily"

Problem: No logs created
   Solution: Run manually first to verify it works
             Check trading_logs/ folder exists
             Check file permissions

Problem: Error in logs
   Solution: Run manually to debug
             Check Alpaca API credentials
             Verify internet connection
             Check bot execution directly

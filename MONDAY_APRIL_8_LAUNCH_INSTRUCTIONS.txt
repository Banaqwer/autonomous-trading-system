===============

Problem: "Connection Failed to Alpaca"
   - Check internet connection
   - Verify API key is correct
   - Verify environment variables set: echo %ALPACA_API_KEY%

Problem: "No signals generated"
   - This is NORMAL some days
   - Algorithm requires specific market conditions
   - Check log for error messages

Problem: "ModuleNotFoundError: No module named 'alpaca'"
   - Install: pip install alpaca-trade-api

   - Double-check API key copy/paste

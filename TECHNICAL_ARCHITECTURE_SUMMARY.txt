TROUBLESHOOTING GUIDE
====================

Common Issues & Solutions:

Issue: Bot won't start
   Solution: Check API credentials set correctly
            Verify environment variables with: echo %ALPACA_API_KEY%

Issue: No signals generated
   Solution: Check data downloaded (should see 40 assets)
            Verify algorithm is receiving data
            Check market conditions (may be no valid signals)

Issue: Trades executing but all losses
   Solution: Check confidence filtering (should be >= 0.25)
            Verify algorithm parameters match backtest
            Check position sizing

Issue: "Insufficient buying power"
   Solution: Reduce position size
            Check risk parameters
            Verify cash available in account

Issue: API rate limits exceeded
   Solution: Reduce check frequency
            Implement request throttling
            Use batch API calls
